# SkyFraze

**Русский** · [English](README.en.md)

Веб-платформа для совместной (по приглашениям) разработки сюжетов игр / кино / мультфильмов / книг:
проект разбивается на главы и под-события, каждое событие показывается отдельным «кадром»
сценического таймлайна, а готовую историю можно открыть публично — с лентой, просмотрами и оценками.

## Что умеет

Главное; полный список — по пункту на фичу — в **[docs/features.md](docs/features.md)**.

- **Сценический таймлайн**: fixed-стадия, скролл переключает кадры; глава, затем её под-события по
  одному развёрнуто (нумерация 01.1, 01.1.1), картинки события — тоже отдельные кадры
- **Markdown в тексте**: заголовки, списки, таблицы, формулы (KaTeX) и диаграммы Mermaid; правится
  в панели и в отдельном окне с живым предпросмотром, сырой HTML запрещён
- **«Связи проекта» — карточки персонажей, мест и тем**: разложены по видам и сворачиваются,
  алиасы, счётчики упоминаний в тексте, хронология, матрица «кто с кем в одной главе», эго-граф,
  связи между карточками и свои типы
- **ИИ-агент «Нестор»** — соавтор проекта: главы и под-события через инструменты, своё имя и своя
  запись участника, роль и указания задаёт владелец, ответ потоком, свой сервер моделей
- **Общий чат проекта** с переключением «обсуждение / чат»: правка и ответы, ссылки на кадр с
  цитатой, `@Нестор` (только чтение проекта), уведомления и письма по согласию человека
- **Выделил фразу в проекте — меню из трёх пунктов**: отправить в чат проекта (поле заполняется
  цитатой со ссылкой на кадр), спросить помощника или **поправить фрагмент** в маленьком окне, не
  уходя с показа; «Открыть в редакторах» ведёт на тот же кусок текста
- **Real-time совместное редактирование** (Yjs/CRDT) с авто-сохранением, присутствие и «печатает…»
- **История версий**: снимки по ходу правок и по кнопке, возврат на любой с предпросмотром
- **Обсуждение кадров**: ветки, `@ник`, реакции, замечания к выделенному фрагменту, колокольчик
- **Книга файлом**: EPUB для читалки и DOCX для правки в Word/LibreOffice — со **своим шаблоном
  оформления** (карта стилей, предупреждения, справка и пример шаблона)
- **Выгрузка и импорт**: проект скачивается лентой `.md` или zip с ассетами, импортируется папкой
  (папка = проект, подкаталоги = главы) или «в место» в существующий проект
- **Команды и роли** (owner / editor / viewer), приглашения, **соавторы** со специализациями,
  каталог **резидентов**, публичная лента с просмотрами и оценками, **корзина** на 30 дней
- **Администрирование развёртывания**: режим регистрации (по умолчанию — по заявке), заявки в
  `/admin`, ключи доступа (WebAuthn), обновление стенда из GitHub Releases
- **«О проекте»** (`/about`): лицензия и уведомления об авторстве, исходники и релизы, документация
  на русском и английском, приватность (телеметрии нет), сторонние компоненты и **номер сборки** от
  сервера; открывается без входа
- Две темы, телефон и «полная версия» на высоком узком экране, 32 e2e-сценария в CI,
  ночной визуальный аудит панели и функциональная матрица, **русский и английский интерфейс**
  целиком: переключатель EN / RU в шапке, выбор запоминается в браузере, `<html lang>` следует за ним

## Стек

| Слой | Технология |
|---|---|
| Backend | Go 1.26+ (multi-stage alpine), chi, pgx, JWT |
| Database | PostgreSQL 15 |
| Object storage | Filesystem или S3/MinIO за одним интерфейсом (`STORAGE_DRIVER`) |
| Real-time | Yjs (CRDT) через WebSocket (gorilla/websocket) |
| Frontend | TypeScript, React 18, Vite, Zustand, ky |
| Сцена таймлайна | иллюстрации/SVG-ассеты + CSS-переходы (fixed-стадия, без WebGL) |
| CI/CD | GitHub Actions |
| Container | docker compose (postgres + backend + nginx-served frontend) |

## Быстрый старт

```bash
git clone --recurse-submodules https://github.com/BarsSky/SkyFraze.git
cd SkyFraze
cp .env.example .env          # заполнить JWT_SECRET (32+ байта в проде)
docker compose up --build -d
curl http://localhost/api/health   # {"status":"ok"}
```

UI — http://localhost, Postgres — `localhost:5432` (`skyfraze` / `skyfraze_dev`). Остановка:
`docker compose down` (с `-v` — вместе с данными, это потеря данных).

**Дальше — `docs/run.md`:** запуск без Docker (dev-режим), режим регистрации и первый
администратор, развёртывание на сервере и обновление из GitHub, перенос проекта между стендами,
все переменные окружения, тесты и живая диагностика, аудит интерфейса, хранение и копии.
Там же — **полное дерево репозитория**.

## Своя команда, свой стенд

SkyFraze задуман так, что каждый может поднять платформу у себя и работать со своей командой над
своими проектами — для этого не нужно ни разрешения, ни регистрации у нас:

* **Развернуть и пригласить своих.** Apache-2.0 разрешает использовать, изменять и хостить код,
  в том числе внутри своей компании или команды. Режим регистрации — по заявке, приглашения и
  роли настраиваются владельцем стенда (`docs/run.md`).
* **Ваши истории — ваши.** Лицензия покрывает программу, а не то, что в ней создано: тексты,
  кадры, карточки и вложения вашего проекта остаются вашими и никуда не отправляются.
* **Никакой телеметрии.** В коде нет ни аналитики, ни «звонков домой»: внешние запросы бывают
  только к тому провайдеру модели, которого вы сами указали (и только если помощник включён).
* **Форки разрешены и ожидаемы.** Единственное условие — при **раздаче** сборки сохранить
  `LICENSE` и `NOTICE` и не выдавать название и логотип SkyFraze™ за свои (Apache-2.0, §4 и §6).

## Архитектура

```
[Browser]                                              [Container]
  React app                                             frontend (nginx)
  ├── fetch /api → same origin → nginx → proxy  ─────►  /api/* ──► backend:8080
  │                                                                   │
  └── WebSocket /api/.../collab → nginx (Upgrade) ─────►            │
                                                                  Go backend
                                                                  ├── chi router
                                                                  ├── Yjs WS relay
                                                                  └── pgx → postgres:5432
```

Подробная диаграмма, модель данных и инварианты — `docs/architecture.md`.

## Структура репозитория

```
SkyFraze/
├── backend/                      Go API: cmd/server + internal/<пакет на область> + migrations/
├── frontend/                     Vite + React + TypeScript: src/ (pages, components, collab, api),
│                                 tests/ (e2e Playwright и живые проверки), nginx.conf, Dockerfile
├── docs/                         разборы решений: что просили, почему так, что проверено
├── deploy/                       скрипты, systemd-юниты и конфиги: обновление, копии, TLS-прокси
├── deps/scroll-world/            git-САБМОДУЛЬ oso95/scroll-world — справочник по композиции
│                                 стадии и механике прокрутки (в сборку не входит)
├── docker-compose.yml            postgres + backend + frontend (локальная разработка)
├── docker-compose.prod.yml       конфигурация для сервера
├── .env / .env.example           JWT_SECRET, ADMIN_EMAILS, REGISTRATION_MODE и т.п.
└── vendor/scroll-world-reference/  локальная копия референса (в репозиторий не входит, /vendor/)
```

Полное дерево — с пакетами `backend/internal`, каталогами `frontend/src/components` и всеми
документами `docs/` — в `docs/run.md`, раздел «Структура репозитория».
