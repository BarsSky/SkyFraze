# Локализация интерфейса: план и ход работ

**Статус: фаза 1 сделана (0.115.0).** Переведена «оболочка»: шапка с навигацией и меню, вход,
регистрация и заявка, страница «О проекте», служебная полоска загрузки. Остальные разделы — на
русском, это ожидаемо: фазы закрываются по областям, недопереведённый интерфейс хуже одноязычного.

Публичные документы двуязычны с 0.112.0–0.113.0 (`README`, `docs/run`, `docs/features`).

## Зачем

Платформу разворачивают у себя, чтобы работать со своей командой. Команда может быть не
русскоязычной, а человек, выбирающий платформу, часто читает по-английски. Английский интерфейс —
следующий шаг после английских документов (0.113.0).

## Сколько переводить (замер, 0.114.0)

Считаны строковые литералы с кириллицей в `frontend/src` (без комментариев, без тестов):

| Область | Строк | Файлов |
|---|---|---|
| `components/` | 773 | 42 |
| `pages/` | 220 | 12 |
| `lib/` | 95 | 11 |
| `api/` | 49 | 8 |
| `collab/` | 8 | 3 |
| **Итого интерфейс** | **1145** | **76** |
| Тесты (переводить не нужно) | 3334 | 90 |

Вывод: это не «добавить словарь», а 1145 строк, разбросанных по 76 файлам. Отсюда — три релиза, а не
один, и жёсткое требование «русский остаётся языком по умолчанию»: 3334 строки в тестах уже
проверяют русские тексты, и смена языка по умолчанию переписала бы половину подписи.

## Решения

1. **Без новой библиотеки.** `react-i18next` тянет плагины, детекторы и рантайм ради того, чего у
   нас нет (загрузка словарей по сети, интерполяция DOM, разделение бандла). Хватает своего:
   типизированный словарь + хук.
2. **Русский — по умолчанию**, английский — выбор человека. Это же сохраняет существующие e2e и
   unit-тесты: они проверяют русские подписи и не меняются.
3. **Язык запоминается в браузере** (`localStorage.skyfraze-lang`) и применяется без перезагрузки.
   Настройка на уровне учётной записи — позже: для одной установки на команду этого мало нужно, а
   поле в базе и миграция — цена, которую платят не сразу.
4. **Перевод — часть кода, а не отдельный каталог `.json`.** Словарь рядом с компонентом и точка
   сбора `src/i18n/ru.ts` / `en.ts`: типы ловят пропущенный ключ на этапе `tsc`, а не в проде.
5. **Язык интерфейса не влияет на данные.** Тексты проектов, названия карточек и сообщения чата не
   переводятся никогда — это авторский текст человека.
6. **Форматирование — через `Intl` с локалью интерфейса:** даты в дереве и версиях, числа в
   счётчиках, «5 минут назад» — иначе английский интерфейс показывал бы «5 минут назад».

## Каркас (фаза 1)

```
src/i18n/
  index.ts        I18nProvider, useT(), useLang(), setLang()
  ru.ts           словарь по разделам: nav, auth, projects, about, common…
  en.ts           тот же тип, что у ru (TypeScript не даст забыть ключ)
  plural.ts       русские формы (1 / 2–4 / 5+): 1 кадр, 2 кадра, 5 кадров
  format.ts       даты и числа через Intl по текущей локали
```

Подписи в компонентах: `const t = useT()` → `t('nav.projects')`, с параметрами —
`t('projects.count', { n })`. Ключ — строка с точками; словарь плоский, чтобы diff оставался
читаемым.

Переключатель: в шапке рядом с темой (RU / EN), на телефоне — в меню «Ещё». Значок языка не нужен:
две подписи короче любой иконки и понятны без легенды.

## Что сделано в фазе 2.2b (0.118.0)

  `aria-label`), фильтр по карточке мира («Только с карточкой», «все кадры», подпись фильтра),
  `aria-label` списка событий, пустые состояния («Ничего не найдено», «Выберите событие слева…»),

* Словарь пополнен сразу под ВСЮ панель (≈100 ключей `ed.*`, включая тексты перетаскивания, отказов

## Что проверять

* `tsc` — пропущенный ключ в английском словаре (тип `Record<Key, string>`) и лишний ключ;
* unit — `plural` на 1/2/5/11/21, `format` (даты, числа), `useT` без провайдера (возвращает русский,
  а не падает);
* e2e — переключение языка в шапке меняет подписи без перезагрузки, выбор переживает перезагрузку,
  язык не влияет на данные проекта;
* аудит интерфейса — английские подписи длиннее: шапка, вкладки, кнопки проверяются на 390 px, иначе
  «Save changes» начнёт переноситься и разъедет строки (ровно это уже ловили на четырёх кнопках
  карточки в 0.102.0).

## Риски

* **Длина строк.** Английский в среднем на 10–20 % короче русского, но подписи вроде «Настройки
  проекта → Project settings» длиннее по словам. Лечится аудитом на 390 px, а не на глаз.
* **Смешение языков.** Пока фаза не закончена, интерфейс будет двуязычным лоскутным — поэтому фазы
  и закрыты по областям.
* **Тесты.** 3334 строки с кириллицей в тестах остаются как есть: они проверяют русский по
  умолчанию. Новые сценарии для английского — отдельным файлом, а не правкой существующих.
* **Даты в CRDT.** Даты кадров хранятся строкой `YYYY-MM-DD`: локализуется только ПОКАЗ, менять
  формат хранения нельзя — иначе поедут импорт, экспорт и предложения помощника.
